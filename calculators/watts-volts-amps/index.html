Equations used

DC: P = V × I. Single-phase AC: P = V × I × PF. Balanced three-phase AC: P = √3 × VLL × IL × PF. Efficiency is applied only to estimate output power from electrical input: Pout = Pin × η. When solving current or voltage, the selected direction returns the corresponding line/RMS value.

This is a simplified sinusoidal AC calculator. Use true PF for non-linear loads. Three-phase mode assumes balanced loading and line-to-line voltage. Efficiency is not a power-factor correction and should be set to 100% when calculating electrical input power.
