Resistor Series & Parallel Calculator

Calculate equivalent resistance for resistor networks connected in series or parallel.

Resistor network

Enter resistor values in ohms, separated by commas. Example: 100, 220, 330.

Enter at least two positive resistor values.

Formula reference

Series

Req = R1 + R2 + … + Rn

Same current flows through each resistor.

Parallel

1/Req = 1/R1 + 1/R2 + … + 1/Rn

Same voltage appears across each branch.

Ideal resistor calculation. Component tolerance, temperature coefficient, power rating, voltage rating, wiring resistance and circuit layout are not included. Check individual resistor dissipation before building a circuit.
