# Enlighted Calc — Hybrid Platform Design System

## Purpose
Enlighted Calc is the engineering knowledge and decision platform of Enlighted Technologies. It combines corporate credibility with practical tools, technical guides and industrial engineering resources.

## Brand position
**Engineering clarity. Practical decisions.**

Core promise: help visitors understand a system, calculate what matters, diagnose problems responsibly and improve technical decisions.

## Experience pillars
1. Engineering Decision Studio — calculators, estimators and transparent calculation methods.
2. Electrical Troubleshooting — structured diagnostic learning and safety-conscious checks.
3. Energy Intelligence — solar, electricity consumption, efficiency and backup planning.
4. Industrial Automation Lab — Modbus, PLC, gateways, telemetry and monitoring.

## Visual system
- Primary navy: #073e63
- Deep navy: #052f4d
- Technical blue: #086b9d
- Cyan accent: #7bd7ec
- Teal accent: #159b9a
- Main text: #142f43
- Muted text: #607789
- Border: #dce7ed
- Soft background: #f2f7fa
- Display typeface: Manrope
- Body typeface: DM Sans

Use colour for hierarchy and navigation, not decoration. Maintain readable contrast, visible focus indicators and consistent spacing.

## Content standards
- Preserve existing public URLs unless a redirect is explicitly planned.
- Preserve existing calculator logic and verify formulas before changing them.
- Explain units, inputs, assumptions and limitations for calculations.
- Cite applicable standards, official references and manufacturer documentation where relevant.
- Do not invent author credentials, product specifications, test results or technical approvals.
- Clearly separate educational guidance from site-specific engineering advice.
- Keep affiliate recommendations contextual, disclosed and secondary to editorial content.

## Navigation model
Primary routes should help visitors reach Electrical, Solar & Energy, Engineering Tools, Industrial IoT, Guides & Reviews and About Enlighted. Existing internal page routes must remain valid even when older page headers use legacy labels during this phased redesign.

## Implementation and release rules
- Work on feature branches; never commit redesign work directly to main.
- Retain current static HTML/CSS/JavaScript architecture unless a demonstrated requirement justifies change.
- Test representative desktop and mobile layouts, navigation, internal links, calculator anchors, SEO metadata and existing monetisation integrations.
- Submit a pull request with screenshots, validation results and known limitations.
- Do not merge or deploy until the repository owner explicitly approves the pull request.
