TROUBLESHOOTING CHECKLIST

When Modbus data is missing or incorrect

  1. Confirm the device address, serial settings or TCP endpoint and network reachability.
  2. Verify the register address convention, function code, data width and signed or unsigned format.
  3. Check byte and word order for 32-bit values and confirm scaling factors.
  4. Review timeout, polling interval, connection limits and gateway logs.
  5. Compare a small set of readings with the device display or a trusted Modbus test client.

Frequently asked questions

What is the difference between Modbus RTU and Modbus TCP?

Modbus RTU commonly runs over serial links such as RS-485. Modbus TCP carries Modbus messages over TCP/IP Ethernet networks.

Why can a Modbus register show the wrong value?

Common causes include address offset, incorrect function code, data type, byte order, word order or scaling. Check the exact device register map.

Is it safe to expose an industrial PLC directly to the internet?

Direct public exposure is generally unsafe. Use a properly designed secure remote-access architecture, strong authentication, network segmentation and approved operational controls.

Industrial control systems are safety- and availability-sensitive. Test configuration changes in a controlled environment and follow equipment manuals, site cybersecurity policy and change-management procedures.
